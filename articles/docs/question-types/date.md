# Add a date question

[Documentation](https://surveyframe.org/articles/docs.md) / [Question
types](https://surveyframe.org/articles/docs.html#question-types)

Add a question and choose Date. The respondent picks it from a calendar.

![SurveyStudio’s Design screen with the date question selected and its

## Settings

- **Required.** Tick it to require a date before the respondent goes on.

## Best practices for research

Ask for a date only when the day matters. For how long ago, a numeric
question is quicker to answer.

Reference: Dillman, D. A., Smyth, J. D., & Christian, L. M. (2014).
*Internet, phone, mail, and mixed-mode surveys: The tailored design
method* (4th ed.). Wiley.
