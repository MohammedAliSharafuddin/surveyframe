# Add a grid of rating questions

[Documentation](https://surveyframe.org/articles/docs.md) / [Question
types](https://surveyframe.org/articles/docs.html#question-types)

Add a question, choose Matrix, list the rows, and pick the scale every
row is rated on.

## Settings

- **Rows.** List the things rated. Each row becomes its own column,
  named after it.
- **Choice set.** Choose the answer options that respondents use to rate
  every row.

## Best practices for research

Keep a grid short: long grids invite the same answer down every row,
which the quality checks flag as straight-lining.

Reference: Dillman, D. A., Smyth, J. D., & Christian, L. M. (2014).
*Internet, phone, mail, and mixed-mode surveys: The tailored design
method* (4th ed.). Wiley.
