# Add a criteria weighting question

[Documentation](https://surveyframe.org/articles/docs.md) / [Question
types](https://surveyframe.org/articles/docs.html#question-types)

Add a question, choose Criteria weight, and list the criteria to divide
100 points across.

## Settings

- **Criteria.** The things weighted. The points must add up to 100.

## Best practices for research

Use points when respondents can judge all criteria at once. For many
criteria, pairwise comparisons are easier to answer.

Reference: Saaty, T. L. (1980). *The analytic hierarchy process*.
McGraw-Hill.
