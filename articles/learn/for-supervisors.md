# Supervising survey research

This page is for a supervisor of students conducting survey research.
Each student’s study is 1 `.sframe` file holding the questionnaire and
analysis plan. You review the plan before collection and compare it with
the report afterwards.

## Before collection: review the plan

1.  **Ask for 2 files:** the pre-analysis plan the student exported from
    SurveyStudio, and the `.sframe` file it was written from.
2.  **Read the plan.** It lists the study, the questionnaire, the scales
    and each research question with its hypotheses, method and decision
    rule. [The analysis
    plan](https://surveyframe.org/articles/learn/analysis-plan.md)
    explains each part.
3.  **Keep the agreed version.** Store the `.sframe` file and the plan
    you approved. The plan names the file’s hash, a fingerprint of its
    contents.

## After analysis: compare the report with the plan

1.  **Check the version.** The report’s Provenance section names the
    hash of the questionnaire analysed. [Verify a `.sframe`
    file](https://surveyframe.org/verify/) to see whether it matches the
    version you kept.
2.  **Compare each research question.** The report prints each result
    beside the decision rule from the plan, with the student’s
    interpretation.
3.  **Inspect the amendments.** The Reproducibility section lists each
    recorded change to the plan with its reason. The list holds the
    changes the student recorded, so compare it with the plan you kept.
