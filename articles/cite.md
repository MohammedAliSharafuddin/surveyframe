# Cite surveyframe

If surveyframe helped your research, please cite it. In R,
`citation("surveyframe")` prints the reference for the version you have.

## APA 7

Sharafuddin, M. A. (2026). *surveyframe: Survey instrument workflows* (R
package version 0.4.3) \[Computer software\].
<https://doi.org/10.32614/CRAN.package.surveyframe>

## BibTeX

    @Manual{surveyframe,
      title  = {surveyframe: Survey Instrument Workflows},
      author = {Mohammed Ali Sharafuddin},
      year   = {2026},
      note   = {R package version 0.4.3},
      url    = {https://CRAN.R-project.org/package=surveyframe},
      doi    = {10.32614/CRAN.package.surveyframe},
    }

## Cite the software and identify the questionnaire

Cite surveyframe itself as described above.

Identify the study’s questionnaire by its title, its version, where it
is preserved (such as OSF) and its SHA-256 hash from the `.sframe` file.
The hash identifies the file and the citation credits the software, so a
reader can check at
[surveyframe.org/verify](https://surveyframe.org/verify/) that the
questionnaire analysed is the one planned.
