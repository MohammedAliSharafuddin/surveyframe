# Reliability plot: alpha and omega by scale

Draws Cronbach's alpha and McDonald's omega for each scale side by side,
against the usual .70 threshold.

## Usage

``` r
sframe_plot_reliability(x, palette = c("web", "print"))
```

## Arguments

- x:

  An `sframe_reliability_report` object from
  [`sframe_reliability_results()`](https://surveyframe.org/reference/sframe_reliability_results.md).

- palette:

  One of `"web"` (brand colours) or `"print"` (black, grey and white).
  See
  [`theme_surveyframe()`](https://surveyframe.org/reference/theme_surveyframe.md).

## Value

A ggplot2 object.

## Examples

``` r
# \donttest{
if (requireNamespace("ggplot2", quietly = TRUE) &&
    requireNamespace("psych", quietly = TRUE)) {
  demo <- sframe_demo("likert_scale")
  rr <- sframe_reliability_results(demo$responses, demo$instrument, omega = FALSE)
  sframe_plot_reliability(rr)
}
# }
```
