# Get survey scales

Returns the scale definitions, including their item membership and
scoring settings.

## Usage

``` r
sframe_get_scales(x, ...)
```

## Arguments

- x:

  A surveyframe object.

- ...:

  Passed to methods.

## Value

An
[sf_component_list](https://surveyframe.org/reference/sf_component_list.md)
for an instrument or a scale data frame for a codebook.
