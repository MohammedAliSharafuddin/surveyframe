# Regression diagnostic plots for a regression_linear result

The 4 standard diagnostic panels (residuals vs fitted, normal Q-Q,
scale-location, residuals vs leverage), built from the plain data frame
[`run_analysis_plan()`](https://surveyframe.org/reference/run_analysis_plan.md)
attaches to a `regression_linear` result, which keeps the result
JSON-serialisable.

## Usage

``` r
sframe_plot_regression_diagnostics(result, palette = c("web", "print"))
```

## Arguments

- result:

  A `regression_linear` result list containing a `diagnostics` data
  frame (as produced internally by
  [`run_analysis_plan()`](https://surveyframe.org/reference/run_analysis_plan.md)).

- palette:

  One of `"web"` (brand colours) or `"print"` (black, grey and white).
  See
  [`theme_surveyframe()`](https://surveyframe.org/reference/theme_surveyframe.md).

## Value

A named list of 4 ggplot2 objects (`residuals_fitted`, `qq`,
`scale_location`, `leverage`), or `NULL` if diagnostics are unavailable.

## Examples

``` r
# \donttest{
if (requireNamespace("ggplot2", quietly = TRUE)) {
  demo <- sframe_demo("correlation_regression")
  res <- run_analysis_plan(demo$responses, demo$instrument)
  panels <- sframe_plot_regression_diagnostics(res$RQ5)
  panels$residuals_fitted
}
# }
```
