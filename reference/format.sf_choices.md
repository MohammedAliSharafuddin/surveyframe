# Format an sf_choices object as a string

Gives the choice set's ID and number of options as 1 line, the line that
[`print()`](https://rdrr.io/r/base/print.html) starts with.

## Usage

``` r
# S3 method for class 'sf_choices'
format(x, ...)
```

## Arguments

- x:

  An object of class `sf_choices`.

- ...:

  Ignored. Present for S3 consistency.

## Value

A single character string.
